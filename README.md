AI Evaluation Rubrics and Scoring Systems

Project Overview

This project demonstrates beginner-level practice in evaluating AI-generated responses using a structured scoring rubric.

The goal is to assess AI responses consistently by examining five important evaluation criteria.

Evaluation Criteria

Each criterion is scored from 1 to 5.

1. Factual Accuracy: Are the claims correct and supported by reliable information?
2. Relevance: Does the response address the user’s question?
3. Completeness: Does it provide enough information to satisfy the request?
4. Clarity: Is the response easy to understand?
5. Instruction Following: Does it follow the user’s requested format, length, and other instructions?

Scoring System

Each response receives a score out of 25.

* 21–25: Excellent
* 16–20: Good, but needs improvement
* 11–15: Fair
* 6–10: Poor
* 1–5: Very poor

These score ranges are practice guidelines, not universal industry standards.

Skills Practised

* Applying structured evaluation rubrics.
* Scoring AI-generated responses consistently.
* Identifying unsupported claims and exaggerated statements.
* Separating factual accuracy from relevance and clarity.
* Evaluating instruction-following.
* Explaining and justifying evaluation decisions.
